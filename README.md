# KlinikKu — Klinik Digital

![React Native](https://img.shields.io/badge/React_Native-20232A?style=flat&logo=react&logoColor=61DAFB)
![Expo](https://img.shields.io/badge/Expo-000020?style=flat&logo=expo&logoColor=white)
![AsyncStorage](https://img.shields.io/badge/AsyncStorage-Local_Persistence-00b894)

> **KlinikKu** adalah aplikasi layanan kesehatan digital berbasis React Native yang dirancang untuk memudahkan pasien dalam memesan jadwal konsultasi dokter secara daring. Aplikasi ini menyelesaikan masalah antrean panjang di klinik dengan menghadirkan sistem booking konsultasi, verifikasi identitas KTP pasien via kamera, serta rekam riwayat medis yang tersimpan secara lokal.

## ✨ Fitur Utama

- [x] Login/Register pasien dengan validasi form & penyimpanan data lokal
- [x] Daftar dokter tersedia dengan pencarian interaktif berbasis FlatList
- [x] Detail dokter & booking jadwal konsultasi dengan navigasi Stack
- [x] Riwayat konsultasi medis tersimpan rapi
- [x] Verifikasi foto KTP pasien via kamera menggunakan `expo-image-picker`
- [x] Data persisten untuk sesi login, booking, & identitas menggunakan `AsyncStorage`
- [x] Bottom Tab Navigation (Home, Riwayat, Profil)

| Layer | Teknologi |
|-------|-----------|
